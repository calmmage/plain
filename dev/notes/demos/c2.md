# C2 Demo - Release Flow

## Purpose
Demonstrate PRD2 release protocol:
- parse `release/release.yaml`
- generate runbook
- evaluate dry-run gates (pass/fail table)
- enforce launch confirmation gate
- execute rollback scaffold and incident note

## Exact Commands
Run:

```bash
make demo-c2
```

The target runs:

```bash
make release-plan
make release-dry-run
uv run python -m tools.release.cli launch --yes
make release-rollback
```

## Expected Output
- runbook generated at `release/runbooks/0.1.0.md`
- release state recorded in `release/state.json`
- dry-run table shows gate status for tests/lint/pyright/migration/smoke
- launch pack files generated:
  - `docs/changelog/0.1.0.md`
  - `docs/launch/0.1.0.md`
- rollback incident file created under `release/incidents/`

## Manual UX Walkthrough
1. Run `make demo-c2`.
2. Open `release/runbooks/0.1.0.md` and review ordered release steps.
3. Inspect `release/state.json` to confirm state transitions after each command.
4. Read dry-run output table and verify required gates are marked PASS/FAIL.
5. Confirm `docs/changelog/0.1.0.md` and `docs/launch/0.1.0.md` exist after launch.
6. Check `release/incidents/` for a rollback incident note template.
