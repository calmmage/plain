# C6 Demo - Review Queue UI (CLI-first)

## Purpose
Demonstrate PRD6 review workspace flow:
- ingest ready-for-review packets
- list all READY items in one table
- verify each item has run instructions + vision reminder
- capture reviewer feedback and status transitions

## Exact Commands
Run:

```bash
make demo-c6
```

The target executes:

```bash
uv run python -m tools.workflow.review_ui.cli ingest \
  --packet-path tests/fixtures/c6/review_packets/2026-02-09-al.md \
  --project-id prj_plain \
  --feature-id feat_review_ui \
  --original-vision "Provide one review workspace with runnable instructions and concise vision reminder."
uv run python -m tools.workflow.review_ui.cli ingest \
  --packet-path tests/fixtures/c6/review_packets/manual_items.json
uv run python -m tools.workflow.review_ui.cli list --ready-only
```

## Expected Output
- first `ingest` returns JSON with:
  - `packets_scanned`
  - `items_created`
  - `items_updated`
  - `blocked_items`
- second `ingest` adds multiple queue entries from one JSON packet file
- `list --ready-only` prints a table with columns:
  - `Status`
  - `Project`
  - `Feature`
  - `Summary`
  - `Original vision`
  - `How to run`
  - `Changed files`
  - `Updated`

## Manual UX Walkthrough
1. Run `make demo-c6`.
2. Verify `blocked_items` is `0` for the packet where `--original-vision` was provided.
3. Confirm ready table shows runnable `How to run` commands.
4. Pick a review id from `data/review_queue/items.json` and run `uv run python -m tools.workflow.review_ui.cli show <review_id>`.
5. Run `uv run python -m tools.workflow.review_ui.cli start <review_id>` and confirm `status: in_review`.
6. Run `uv run python -m tools.workflow.review_ui.cli request-changes <review_id> --notes "Need clearer expected output."`.
7. Run `uv run python -m tools.workflow.review_ui.cli approve <review_id> --notes "Addressed."` and verify feedback history is appended.
