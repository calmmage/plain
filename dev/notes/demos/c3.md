# C3 Demo - Principles to Skills

## Purpose
Demonstrate PRD3 protocol:
- capture principle note in under a minute
- promote principle into skill candidate
- generate `SKILL.md` asset
- run rubric-based `test-skill`
- approve candidate and deploy approved bundle to instruction files

## Exact Commands
Run:

```bash
make demo-c3
```

The target performs:

```bash
P_ID=$(uv run python -m tools.workflow.principles.cli capture ...)
C_ID=$(uv run python -m tools.workflow.principles.cli promote "$P_ID" --skill-name concise-coordinator --scope coding)
uv run python -m tools.workflow.principles.cli test-skill "$C_ID" --prompt "Validate concise coordinator behavior for coding tasks"
uv run python -m tools.workflow.principles.cli approve-skill "$C_ID"
uv run python -m tools.workflow.principles.cli deploy --target AGENTS.md --target CLAUDE.md --target GEMINI.md
uv run python -m tools.workflow.principles.cli list --status approved
uv run python -m tools.workflow.principles.cli list-candidates --status approved
```

## Expected Output
- principle note written to `dev/notes/ecosystem/principles/inbox/<principle_id>.md`
- candidate note written to `dev/notes/ecosystem/principles/candidates/<candidate_id>.md`
- generated skill file at `skills/local/concise-coordinator/SKILL.md`
- approved principle moved into `dev/notes/ecosystem/principles/approved/`
- bundle created at `dev/notes/ecosystem/principles/approved/bundle.md`
- instruction files contain a managed principles block between:
  - `<!-- principles:begin -->`
  - `<!-- principles:end -->`

## Manual UX Walkthrough
1. Run `make demo-c3`.
2. Inspect the newly created principle file in `dev/notes/ecosystem/principles/inbox/`.
3. Open candidate file in `dev/notes/ecosystem/principles/candidates/` and verify status progression.
4. Open `skills/local/concise-coordinator/SKILL.md` and confirm required sections (Intent, Trigger Conditions, Step Protocol, Output Contract, Anti-patterns, Examples).
5. Check `dev/notes/ecosystem/principles/approved/bundle.md` for consolidated approved rules.
6. Confirm `AGENTS.md`, `CLAUDE.md`, and `GEMINI.md` include the managed principles block.
