# C7 Demo - Bootstrap Scenarios

## Purpose
Demonstrate PRD7 scenario catalog and runner:
- list predefined start/finish scenarios
- run one finish scenario in observe mode
- resume paused run through interactive checkpoint confirmation
- inspect stored run history

## Exact Commands
Run:

```bash
make demo-c7
```

The target executes:

```bash
uv run python -m tools.workflow.bootstrap.cli list
RUN_ID=$(uv run python -m tools.workflow.bootstrap.cli run quality_gate_finish --observe | awk -F': ' '/^run_id:/{print $2}')
uv run python -m tools.workflow.bootstrap.cli resume "$RUN_ID" --interactive
uv run python -m tools.workflow.bootstrap.cli runs --scenario-id quality_gate_finish
```

## Expected Output
- `list` prints scenario catalog rows with:
  - scenario id
  - kind (`start`/`finish`)
  - tags and step count
- `run` returns a run payload including:
  - `run_id`
  - `status` (typically `paused` at human checkpoint in observe mode)
  - `completed_steps`
  - step result summaries
- `resume` transitions the paused run to `done` after checkpoint confirmation
- `runs` shows historical run table for the selected scenario

## Manual UX Walkthrough
1. Run `make demo-c7`.
2. Confirm `list` output includes 3 start and 3 finish scenarios.
3. Inspect `run` output and verify it paused at `human_gate`.
4. Check `resume` output and confirm status changes to `done`.
5. Open `data/bootstrap_runs/<run_id>.json` and verify:
   - step records
   - notes
   - completed step ids
6. Re-run with `--allow-destructive` only when intentionally testing commands that match destructive patterns.
